category: infrastructure
file: main.go
summary: Port & sandbox settings, CGO disabled, graceful shutdown, graceful ONNX/SQLite startup.
details: |
  * Server listens on the port chosen by `infrastructure.ResolvePort`, which
    already prefers an explicit `--port` over the `.env` `BRIDGE_PORT`, then
    `BRIDGE_PORT`, then the bundled `.env`, then 8080.
  * `http.Server` is configured with `Read/Write/IdleTimeout`, listens on
    `:PORT`, and shuts down gracefully on `SIGINT`/`SIGTERM`.
  * `ONNX_AUTO_DOWNLOAD=0` disables the first-run ONNX artefact download
    (useful when the image ships `models/` or is offline).
  * `BRIDGE_DB` overrides `--db` (SQLite file path).
  * `BRIDGE_PORT` / `BRIDGE_DB` are the variables Render's UI sets, so the
    app needs no `.env` provisioning beyond secrets.
