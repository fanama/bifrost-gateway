Appeler cette API en curl

Le modèle est celui de la configuration active du projet ({{.DefaultModel}}) : inutile de le préciser dans le corps de la requête. Seuls messages est requis. 

curl -X POST {{.BaseURL}}/v1/chat/completions \
  -H 'Content-Type: application/json' \
  -H 'Authorization: Bearer sk-bridge-VOTRE_CLE' \
  -d '{
    "messages": [
      {"role": "user", "content": "Bonjour"}
    ]
  }'

Pour changer de modèle, activez une autre configuration depuis la page du projet — un model dans le corps est ignoré. La réponse est au format OpenAI : lire choices[0].message.content.
