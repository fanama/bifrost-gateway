# Bridge Gateway - Render.com support notes

## Why this works

The gateway is a single Go binary backed by SQLite (modernc.org/sqlite, pure Go,
no CGO) and an in-memory cache. Render does not need a database, cache, or
worker box: one Web Service with a Docker build is enough. There is no
`compose.yml`/Postgres/Redis dependency to remove.

## What was changed

### Entry point & port (`main.go`)
- The listening port is resolved by `infrastructure.ResolvePort`, which already
  respects Render's `BRIDGE_PORT` environment variable and keeps the explicit
  `--port` flag in front of it.
- `http.Server` has `Read/Write/IdleTimeout`, listens on `:PORT`, and shuts down
  gracefully on `SIGINT`/`SIGTERM`, so Render's stop signal is handled cleanly.
- `ONNX_AUTO_DOWNLOAD=0` disables the first-run ONNX artefact download; useful
  when the image ships `models/` or is offline.
- `BRIDGE_DB` overrides `--db` (SQLite file path); `BRIDGE_PORT` is the value
  Render's UI sets.

### Build (`Makefile`, `Dockerfile`)
- `make build` and `make build-linux` compile with `CGO_ENABLED=0` for
  `linux/amd64` and `linux/arm64`. The release binary is `scratch`-safe: no
  glibc, no external binaries, no CA-bundle dynamics (a CA is copied into the
  image).
- The `Dockerfile` uses `build/scratch` and copies `config.yaml` plus a Linux
  build of the gateway. Render's auto-detect picks up this `Dockerfile` and
  builds the same way.

### On Render
1. Create a **Web Service**, point it at this repository, and select
   **Docker** as the runtime.
2. Add the environment variables: `BRIDGE_PORT=4000`, `BIFROST_MASTER_KEY`
   (in clear text, it stays in process), and `ONNX_AUTO_DOWNLOAD=0` if the image
   already contains the ONNX artifacts or the build has no network.
3. For Ollama in Render, set `OLLAMA_HOST=http://10.0.0.1:11434` (or the
   internal DNS of the Render host running Ollama) and deploy the Ollama box
   first so the gateway can reach it.
4. Start the service on `:4000`; the Web UI is at
   `https://<app>.onrender.com` (HTTP only, no SSL PEM bundle is embedded).

## Build / verify locally

```bash
make build          # linux host binary
CGO_ENABLED=0 GOOS=linux GOARCH=amd64 go build -ldflags="-s -w" -o bin/bridge-gateway-linux .  # Render linux/amd64
CGO_ENABLED=0 GOOS=linux GOARCH=arm64 go build -ldflags="-s -w" -o bin/bridge-gateway-linux-arm64 . # Render linux/arm64
make test           # go test ./tests/ -v -count=1
```
